## Response

This activity reminded me of our current project because our robot currently uses a A* path to navigate and move around/avoid obstacles and people. It is interesting to see the other types of search paths and how each type of search has its own strength and uses. There were a few new searches that I wasn't familiar with and seeing how they work was pretty cool. It also put into prospective how many decisions a robot has to make to complete any route, whether it is a simple route or not. There were some searches that I found to be annoying like DFS, where it would search more spaces than it needed to which would cause a timeout because it was taking too much to actually get to the goal, and then it would never actually make it. This activity stressed the importance of creating an effective path that does what it is intended to do in a safe way.
