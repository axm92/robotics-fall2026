If we were to put this robot motion program from mission 3 into physical hardware there could be a multitude of outcomes. For example, if that robot it placed on the streets of New York, where cars and pedestrians are all over the place there is no telling how the program would handle it. There could be too much sensor noise, and the robot shuts down or can move uncontrollably or unpredictably. For a program to succeed as part of a sociotechnical system we would need to repeatedly test it in the environments it would be placed in. In my opinion, it would be best to test the program to many possibilities like heavy sensor noise, or multiple obstacles.
