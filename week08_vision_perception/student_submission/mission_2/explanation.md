# mission_2

## comparison
When observing the table I could see that in the normal images, the learned detector did a lot better than the classical one. It had 2 correct boxes, 0 false boxes, and 0 missed mugs, while the classical had 0 correct boxes and 2 missed mugs. In the dim and occluded images, neither detector found the mug so they both had 0 correct boxes. It is important to point out that they failed in different ways though. The classical detector drew 2 false boxes in each condition, but the learned detector drew none and just missed the mug. This difference is matters because a wrong box could send a robot to the wrong spot, while a missed object is easier to notice and much safer. The paired image for normal_1 shows the difference clearly, the classical box was much larger than the reference box because it included the mug's shadow and a part of the desk, leading to the center being the desk and not on the mug. The learned box sat right on the mug and was labeled cup, although it left out the handle. 

## choice
I recommend the learned detector for further testing, because it was the only one that placed a correct box on the mug and didn't make a false box. I would keep an acceptance threshold at 0.35 so that the false boxes stay at zero, and then try a lower threshold on the dim and occluded images to see if some of the missed mugs can be recovered. The learned detector is slower, at about 43 to 49 ms per image compared with 7 to 9 ms for the classical one, but both are fast, and this is processing time per image, not robot response time, so it should not decide the choice. For the foreground mask on normal_1, the mask IoU was 0.4760 and the Dice was 0.6146, so the mask only partly overlapped the reference. Even a very detailed mask would not tell us which object is the requested mug, because it only separates objects from the background, and the laptop, keyboard and trackpad are foreground too. The system still needs a label like cup, and cup also covers other cups. One important limit is that this was a very small test, with only 3 images per condition and a single mug scene, so one image changes the result a lot, and the numbers show a rough pattern and not a firm conclusion.
